# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级、必带标记和携带数量
- 同一物品按种类编辑数量，装箱时每件副本独立占用空间和重量
- 摆放图可定位具体的一件副本，并显示每类计划/已装入/未装入数量
- 数量减少时先撤未装入副本、再按固定顺序撤已装入副本，保留其余副本身份
- 必带物品必须全部数量装入才算齐全，部分装入明确提示尚缺件数
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、必带品缺件、易碎品受压和重心风险
- localStorage 本地保存（旧记录默认一件）与打印清单

## 数量与副本规则

- 数量必须是大于 0 的整数，零、负数和小数无法保存；没有数量字段的旧记录默认按 1 件迁移。
- 清单按种类维护一行，总数与总重量按副本展开（单件重量 × 数量）。
- 装箱引擎逐件尝试摆放：每一件副本都独立检查承重、体积和碰撞，并携带稳定的副本序号。
- 修改数量后三套方案立即按副本对账：减少数量时以当前选中方案为基准，先撤尚未装入的副本（大号序号优先），再按固定顺序撤已装入的副本，其他副本的序号和勾选位置保持不变；点击“智能装箱”后完整重算。
- 打印与刷新后的已装件数、总重量始终与实际副本一致。

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

```bash
npm install

npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。
